## 📖 About The Project

**Kawoinator** is a Java-based desktop application built in IntelliJ IDEA. While it technically fulfills the requirements of a standard coffee maker simulation, it completely overhauls the theme into a *Phineas and Ferb* parody. 

Instead of simply brewing coffee, the machine "corrupts" it. The user interacts with a fully themed GUI featuring custom sound effects, dynamic progress bars, and probability-based mini-games to achieve the ultimate goal: conquering the Tri-State Area.

### ✨ Key Features
*   **Thematic Audio Integration:** Clicking the "Uruchom machine zła" (Start the evil machine) button triggers the iconic *Doofenshmirtz Evil Incorporated* audio jingle.
*   **Corrupted Brews:** Select from a menu of dark concoctions, such as *Zielona Kapuczyna* (Green Crap-uccino), *Pieklolatte* (Hell-latte), *Czarna Groza* (Black Terror), or *Kofeina Chaosu* (Caffeine of Chaos).
*   **Tri-State Area Conquest:** Once the coffee "comes to life," players can attempt to take over the Tri-State Area. The success rate is mathematically tied to the selected evilness slider (*Evil, Very Evil, Seriously Dangerous*). 
*   **Agent P Intervention:** If the conquest probability rolls a failure, the attempt is thwarted by a surprise appearance from Perry the Platypus.
*   **Self-Destruct Sequence:** Like any true Inator, the machine features a highly prominent Self-Destruct button. Pressing it triggers a multimedia meme explosion (complete with video and audio).

## ⚙️ Installation & Execution

To run this evil invention locally, you need the **Java Development Kit (JDK)** and **IntelliJ IDEA**.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/AirNicolas54382/Kawoinator
    ```
2.  Launch **IntelliJ IDEA**.
3.  Open the downloaded project folder.
4.  Navigate to the `src` folder in the Project Explorer.
5.  Right-click the main class file and select **▶ Run**.
6.  *Note: Make sure your speakers are turned on to experience the full Doofenshmirtz effect.*
